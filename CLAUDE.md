# Project Guidelines: Portfolio Site

## Asset Naming Conventions
All media assets should be stored in `public/assets/` and follow a `kebab-case` naming convention (lowercase letters and hyphens).

### 📸 Photography (`/assets/photography/`)
- **Pattern:** `[subject]-[description]-[number].jpg`
- **Example:** `city-skyline-night-01.jpg`
- **Goal:** Descriptive names for SEO and organization.

### 🎥 Videography (`/assets/videography/`)
- **Pattern:** `[project]-[shot-type]-[number].mp4`
- **Example:** `music-video-drone-sweep-01.mp4`

### 🎨 Design (`/assets/design/`)
- **Format:** Use `.jpg` (instead of .png) for design photos.
- **Pattern:** `[client/project]-[deliverable]-[version].jpg`
- **Example:** `brand-logo-minimal-v2.jpg`

### General Rules
- No spaces or uppercase letters in filenames.
- Group related items by starting the filename with the project name (e.g., `summer-jam-crowd.jpg`, `summer-jam-lead-singer.jpg`).
